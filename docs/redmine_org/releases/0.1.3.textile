h3. redmine_expert_agile 0.1.3 — 2026-08-10

h4. Fixed

* *Board options were lost on the next page load.* Statuses, WIP limits, swimlanes and colour basis lived only in the URL, so setting a WIP maximum and reloading reverted everything. The board now keeps its configuration in the session, as Redmine's own issue list does.
* *Anyone able to save a board could edit and delete other people's private boards.* @editable_by?@ ignored ownership; it now mirrors Redmine's rule — your own boards are yours, public project boards need the manage permission, global boards are admin-only.
* *Saving a board never worked*: the controller used @safe_attributes@, which @Query@ does not implement. Attributes are assigned explicitly now, and visibility only with the manage permission.

h4. Upgrade notes

No migrations. Replace the plugin directory and restart.
