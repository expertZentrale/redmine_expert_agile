h3. redmine_expert_agile 0.1.6 — 2026-08-11

h4. Added

* *More card fields.* Created and updated were already selectable; the picker now also offers *time in status* — whole days since the issue last changed status, answered from one grouped journal query for the whole board rather than a lookup per card — and a *short excerpt of the description*, whose length is configurable in the plugin settings. Description is a block column in Redmine, so the options panel now exposes block columns the way Redmine's own query form does.
* The excerpt is plain text: HTML and wiki markup are stripped rather than rendered. A card is a summary, and descriptions ingested from email are mostly HTML.

h4. Fixed

* *A setting added in a later version never took effect on an existing installation.* Redmine returns the stored settings hash wholesale once the form has been saved once, so a newly declared key is absent and reads as nil — for a numeric setting, 0. The declared defaults are now merged underneath the stored values: a stored value still wins, including a deliberately blank one, while new keys get their default.

h4. Upgrade notes

No migrations. Replace the plugin directory and restart.
